# 五份常用查询提示词

在已连接 fanqie MCP 的 Agent 对话框粘贴。本人数据先核对身份；作品 ID 从本轮工具返回选择。服务 Token 和二维码不要复制到公开反馈中。

## 1. 找一篇课程并阅读

```text
使用 fanqie MCP 获取作家课堂写作技巧目录（category="3"）。
列出与“人物动机”相关的课程；根据目录标题筛选，不声称平台提供关键词搜索。
从本轮结果选一篇，用 articleId 读取正文，给出三个可实践的要点与来源链接。
报告 sourceMode、完整性与采集时间；图片或视频未转写时明确说明。
```

## 2. 确认登录并列作品

```text
先调用 fanqie_check_login_status，报告账号昵称、稳定标识和检查时间。
未确认本人账号时停止作品查询；需要扫码时只展示二维码，等我完成扫码后重新核验。
身份确认后，列出我的短故事作品（kind="short"），保留稳定ID和完整性。
不执行任何草稿维护、投稿或发布操作。
```

## 3. 解读经营数据

```text
确认当前登录账号，读取我的长篇作品经营数据（kind="long"）。
按平台原始字段整理每部作品的指标，保留统计窗口、截止时间、时区与limitations。
无法证明的字段写 unknown，不推算昨天，不把缺失值当0。
报告 sourceMode、分页完整性与部分失败；只有完整数据才给出全量比较。
```

## 4. 查章节目录并阅读一章

```text
核对当前登录账号，列出我的长篇作品让我选一部。
使用我选定作品的稳定workId读取管理章节目录与草稿目录，分别说明完整性。
等我选定本轮唯一chapterId后，调用fanqie_get_chapter读取该章当前作者编辑版本。
标明这是作者当前版本，不能证明与已发布正文一致。不打开编辑器，不保存或发布。
```

## 5. 查看保存的数据

```text
只读取本地历史，不访问番茄平台：调用fanqie_get_saved_snapshot，scope="account"。
保留sourceMode="saved"、原采集时间和数据完整性，不称为今天的实时结果。
若没有完整账号快照，明确说明为空，列出已有历史scope供我选择，不自动刷新。
```

`account` 快照需要此前完成四数据集完整刷新。课堂历史按分类保存：提示词 1 查询技巧专区，对应 `scope="writer_classes.tab3"`；新手专区为 `writer_classes.tab1`；省略 `category` 查询所有分类时才用 `writer_classes`。若只查过短故事作品，用 `scope="short_works"`。超时先查已有任务，避免连续重发。
